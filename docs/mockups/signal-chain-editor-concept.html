Signal chain

fixed position reorderable

Confirmed real-hardware structure (2026-07-26)

  • Input is always first, Output is always last — both fixed.
  • Amp and Cab are separate blocks, but always adjacent — Amp immediately before Cab. This pair's position is fixed; it cannot move.
  • Every other block (Wah, Volume Pedal, Distortion, Mod, Delay, Reverb, FX Loop, FX1, FX2) can be freely reordered before or after the Amp/Cab pair, in any order.

Still open

  • Whether the unit exposes chain reordering via MIDI/SysEx at all, or whether this would be an app-only concept layered on top — likely tied to the still-undecoded Bulk Rig/Rig Description structure.
  • Whether Cab has independently configurable parameters (cabinet type, mic model, mic position) beyond what's currently modeled — Amp/Cab is currently one combined effect in EffectDefinitions.
  • This mockup's block styling/interaction pattern reuses the existing EffectEditorComponent control types (knob/toggle/selector) — not yet reconciled with how reordering itself would be triggered (drag handles, arrows, etc.).
