Main Volume is live two-way synced with the unit, shown on its own 0.0-10.0 display scale (not the raw signed wire value). Tuner has no query anywhere in the protocol - the status line only ever reflects a real device-confirmed change, never an optimistic guess from clicking a button, which is why On/Off are separate buttons rather than a single toggle. Tap Tempo (CC 64) is momentary - one tap per click, nothing to read back or sync. FX Loop uses fixed CCs (Bypass 107, Send 19, Return 108, Mix 88), not the "Setting N" positional scheme every effect slot below uses. No live readback for FX Loop's three knobs, same limitation as every other slot's per-knob values.
