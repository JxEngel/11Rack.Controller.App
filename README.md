# Eleven Rack Controller App

A from-scratch replacement editor for the AVID Eleven Rack, since AVID's original
Editor/Librarian no longer runs on modern Windows.

- New here? Start with [docs/project-overview.md](docs/project-overview.md) for the background
  and decisions, then [docs/development-guide.md](docs/development-guide.md) to get building.
- [docs/protocol-spec.md](docs/protocol-spec.md) - the technical reference (MIDI CC table + SysEx
  protocol details).
- [docs/implementation-plan.md](docs/implementation-plan.md) - the trackable task checklist.
